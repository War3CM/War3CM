## ⚡ All-In-One Powerhouse Features

### 🎮 Seamless Play & Auto Save Sync
- **Direct Play Map:** Launch any RPG map with your chosen save profile mounted instantly.
- **Safe Auto-Sync:** Your in-game progress, inventory, and stats automatically synchronize back into your save slot the moment you exit the game. Never lose progress again!

### 👑 Map Level Customization (1–100) & Rank 1 Status
- **Custom Map Level (1–100):** Enter your desired map level directly inside the launcher. Synchronizes across both **DzAPI** and **KK Platform (KKAPI)** standards.
- **Instant Rank 1:** Unlock top-tier leaderboards, exclusive visual titles, and VIP character perks with a single click.

### 💾 VIP Save Import & Character Slot Isolation
- **Load Save (VIP):** Easily import shared VIP saves, donor perks, or your friends' `.ini` save files with custom slot naming.
- **Unlimited Profiles:** Create dedicated character slots for multiple heroes, classes, and playthroughs.

### 🖥️ Modern In-Game Quality-of-Life Tuning
- **16:9 Widescreen Support:** Native widescreen camera viewport for modern 1080p, 2K, and 4K displays.
- **4:3 Aspect Ratio Fix:** Prevents stretched graphics in windowed mode.
- **Mouse Lock:** Keeps your cursor locked inside the game window during windowed or borderless play.
- **Fast Load:** Drastically cuts down map loading times.
- **Mute Save Spam:** Eliminates annoying repetitive score popups during auto-saves.

### 🌐 Native 10-Language Support
