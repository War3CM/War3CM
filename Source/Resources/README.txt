Warcraft Platform Manager icon kit

Use WarcraftPlatformManager.ico as the EXE application icon. The ICO contains 16, 20, 24, 32, 40, 48, 64, 128, and 256 px images. The SVG is editable; PNG exports have transparent surroundings.

The companion source ZIP already adds ApplicationIcon in Phanmemwar3.csproj and sets Form.Icon in the launcher and dialogs. Rebuild the EXE on Windows with the .NET 8 Windows Desktop SDK; replacing an existing executable without rebuilding will not update its embedded icon.
